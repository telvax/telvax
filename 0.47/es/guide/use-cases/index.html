Casos de uso

Para qué sirve Telvax, con un programa para cada caso que puedes ejecutar desde la raíz del repositorio. Todos los programas de abajo están en examples/ y se ejecutan con los comandos que se muestran.

Quieres Mira Se ejecuta con
Resumir un archivo CSV o Parquet dataframe/sales.tvx telvax run
Comprobar las formas de un modelo antes de ejecutarlo ml/forward.tvx telvax run
Servir una función por HTTP service/sentiment.tvx telvax serve
Montar un servicio de RAG rag-service.tvx telvax serve
Procesar texto text/word-count.tvx telvax run
Manejar errores sin excepciones errors/parse-config.tvx telvax run
Escribir código numérico sencillo basics/primes.tvx telvax run, o nativo con telvax build

1. Análisis de datos en tablas

Sección titulada «1. Análisis de datos en tablas»

Una Table[Row] es una tabla Arrow cuyas columnas son los campos del tipo Row. Los nombres y los tipos de las columnas se comprueban antes de que el programa se ejecute, y una columna se lee como un tensor sin copiarla.

Úsalo para informes, preparación de features y comprobaciones rápidas de un archivo de datos. Una columna mal escrita (sales.prise) es un error de compilación (no column prise on type Table[Sale]) en lugar de un fallo a mitad de la ejecución. SQL (y Parquet) necesitan la compilación completa; telvax-lite mantiene las tablas en memoria y lee CSV.

2. Modelos con formas comprobadas

Sección titulada «2. Modelos con formas comprobadas»

Las formas de los tensores forman parte del tipo, así que un producto de matrices con formas que no coinciden no compila:

Cambia los pesos de layer1 a Tensor[f32, 4, 4] y telvax check informa de matmul inner dimensions differ: 3 and 4 en la llamada. Usa dimensiones simbólicas (Tensor[f32, N, 3]) cuando un tamaño solo se conoce en tiempo de ejecución. Aquí los pesos vienen de std.tensor.from_vec; un modelo real los cargaría de un archivo o de una tabla.

3. Servir una función por HTTP

Sección titulada «3. Servir una función por HTTP»

@endpoint convierte una función en una ruta. El tipo del parámetro es el cuerpo JSON y se valida por ti; Err(Status.BadRequest(...)) se convierte en un 400.

Para publicarlo, telvax build --serve examples/service/sentiment.tvx -o service --dockerfile produce un solo binario con el programa incrustado, más un Dockerfile.

6. Errores como valores

Sección titulada «6. Errores como valores»

No hay excepciones. Una función que puede fallar devuelve Result[T, E] o T?, el match debe cubrir todos los casos, y ? pasa un error a quien llamó.

7. Código numérico sencillo, interpretado o nativo

Sección titulada «7. Código numérico sencillo, interpretado o nativo»

Los enteros, los floats, los bucles y los tipos propios también funcionan como en un lenguaje corriente. El intérprete ejecuta cualquier cosa; el backend nativo (--features llvm) compila el subconjunto descrito en el README.

Más allá de un archivo

Sección titulada «Más allá de un archivo»
  • Varios archivos y paquetes: from util import helper y tvpm, mira el recorrido.
  • Muchas máquinas: std.dist.map con telvax worker, mira el recorrido.
  • Desde Python: el módulo python/ intercambia tablas Arrow y arrays de NumPy sin copiar.
  • En el navegador: el playground ejecuta el comprobador y el intérprete como WebAssembly.
  • Editor: telvax lsp y la extensión de VS Code dan diagnósticos, hover y autocompletado.

Cuándo Telvax todavía no es la herramienta adecuada

Sección titulada «Cuándo Telvax todavía no es la herramienta adecuada»

Está en alfa. El backend nativo cubre un subconjunto pequeño, la salida PTX y StableHLO no se ha ejecutado en GPU de NVIDIA ni en TPU, y la sintaxis todavía puede cambiar. docs/design/status.md lista lo que se verificó y cómo.
